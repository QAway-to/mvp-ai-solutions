# mvp-ai-solutions

Лендинг под оффер «AI решения для вашего бизнеса»: внедрение ИИ в процессы малого
и среднего бизнеса. Одна страница под платный трафик, заявки уходят в Telegram.

**Стек:** Astro 7 (статическая сборка) + Tailwind 4, отдача и приём заявок — `server.mjs`
на Node 22, хостинг — Render Web Service.
**Дизайн-система:** Stripe из [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/stripe/DESIGN.md).

## Запуск

```bash
npm install
npm run dev          # http://localhost:4321
```

Форма заявки в `npm run dev` не работает: `/api/lead` живёт в `server.mjs`, а не в Astro.
Чтобы проверить её целиком — собрать и поднять как в проде:

```bash
npm run build
TELEGRAM_BOT_TOKEN=... TELEGRAM_CHAT_ID=... npm start   # http://localhost:10000
```

## Переменные окружения

Список — в `.env.example`. Задаются в панели Render (Environment), в репозиторий не коммитятся.

| Переменная | Зачем |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен бота от [@BotFather](https://t.me/BotFather). Только сервер видит его: форма шлёт заявку на свой же `/api/lead`, иначе токен уехал бы в браузер каждого посетителя. |
| `TELEGRAM_CHAT_ID` | Куда бот пишет заявку: свой user id или id группы (у групп он с минусом). |
| `PUBLIC_SITE_URL` | Базовый адрес для canonical, OG-тегов и sitemap. |

Без первых двух сайт открывается, но форма отвечает 503 и пишет предупреждение в лог —
одна забытая переменная не должна ронять страницу целиком.

### Куда направлять заявки

**В закрытую группу, не в канал.** В группе на заявку можно ответить реплаем, отметить
реакцией «взял в работу» и позже добавить второго человека, ничего не перенося. Канал
вещательный: обсуждать заявку в нём нечем, а если канал публичный — контакты клиентов
окажутся на виду у подписчиков.

Личка бота тоже рабочий вариант, если работаешь один, но заявки быстро тонут среди
остальной переписки и разделить их потом не с кем.

Как получить `TELEGRAM_CHAT_ID` для группы:

1. Создать группу и добавить в неё бота.
2. У [@BotFather](https://t.me/BotFather) снять с бота privacy mode
   (`/setprivacy` → Disable), иначе он не видит сообщения группы.
3. Написать в группу любое сообщение.
4. Открыть `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и взять `message.chat.id`.

У групп значение отрицательное, у супергрупп начинается с `-100`. Для лички туда
кладётся собственный user id.

## Где что править

| Что | Где |
|---|---|
| Весь текст лендинга: заголовки, услуги, тарифы, FAQ | `src/content/offer.ts` |
| Название, домен, контакты, мета-описание | `src/config/site.ts` |
| Цвета, типографика, кнопки, карточки | `src/styles/global.css` |
| Порядок секций на странице | `src/pages/index.astro` |
| Приём заявки, лимиты, отправка в Telegram | `server.mjs` |

Разметка текст не содержит — компоненты только рисуют то, что лежит в `offer.ts`.

## Перед запуском рекламы

- [ ] `src/config/site.ts` — заменить `brand` и `legalName` (сейчас там заглушка
      `AI Solutions`). Контакты уже боевые: `@aimindset`, `toaifuturesad@gmail.com`
- [ ] `src/content/offer.ts` — сверить цены в `pricing` с реальным прайсом
- [ ] `public/og.png` (1200×630) — положить и раскомментировать `og:image`
      в `src/layouts/Landing.astro`, иначе ссылка в мессенджере выглядит пустой
- [ ] `public/robots.txt` и `PUBLIC_SITE_URL` — поправить адрес после привязки домена
- [ ] Отправить тестовую заявку и убедиться, что она дошла в Telegram
- [ ] Перевести сервис на платный план: на free-плане контейнер засыпает
      через 15 минут тишины, и первый посетитель из рекламы ждёт холодного старта

## Отзывы

`testimonials` в `offer.ts` — пустой массив, и секция отзывов из-за этого не рисуется.
Так задумано: заполнять её нужно настоящими отзывами настоящих клиентов. Выдуманные
цитаты на странице, которая принимает платный трафик, — это не заглушка, а обман
посетителя, и стоит он дороже, чем пустое место в макете.

## Деплой

Render, автодеплой с `main`. Настройки сервиса — в `render.yaml`, но заведён он в панели
руками: тариф и переменные окружения живут там, а не в blueprint.
